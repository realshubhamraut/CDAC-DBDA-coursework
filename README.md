# CDAC Post Graduate Diploma in Big Data Analytics

A comprehensive repository documenting my learning journey through the Post Graduate Diploma in Big Data Analytics (PGDBDA) program at CDAC Kharghar. This repository contains course notes, practical assignments, hands-on projects, and implementation of key concepts in big data analytics.

## Overview

The PGDBDA program is a rigorous 12-month course designed to develop expertise in modern big data technologies, analytics, and machine learning. The curriculum covers the complete spectrum of data science—from fundamentals of programming and databases to advanced machine learning and big data ecosystem tools.

### Core Competencies

**Programming & Scripting**
- Python, R, and Java programming
- Linux shell scripting
- Data structures and algorithms

**Database Technologies**
- Relational database design and SQL
- NoSQL databases (MongoDB, Cassandra)
- Data warehousing and ETL concepts

**Big Data Ecosystem**
- Hadoop and HDFS
- Apache Spark (RDDs, DataFrames, MLlib)
- Hive, HBase, and Kafka
- Data lake architecture

**Analytics & Machine Learning**
- Statistical analysis and hypothesis testing
- Supervised and unsupervised learning
- Deep learning and neural networks
- Natural language processing
- Generative AI and large language models

**Data Visualization & Business Intelligence**
- Tableau dashboards and reporting
- Visualization principles and best practices
- Business intelligence workflows

## Module Details

### Module 1: Linux Programming & Cloud Computing
Covers Linux system administration, shell scripting, version control (Git/GitHub), and cloud platform basics including AWS and Azure deployment.

### Module 2: Programming Languages

**Python**
- Core concepts: data types, control flow, functions, OOP
- Libraries: NumPy, Pandas, Matplotlib, Seaborn, Beautiful Soup
- Data wrangling and transformation

**R Programming**
- Data manipulation with tidyverse and dplyr
- Statistical analysis and visualization
- Statistical modeling

**Java**
- Object-oriented programming principles
- Collections framework and JDBC
- Database connectivity

### Module 3: Database Systems
Relational database design, SQL (DDL, DML, DCL), NoSQL databases, data warehousing concepts, and ETL pipeline implementation.

### Module 4: Big Data Technologies
Distributed computing with Hadoop, MapReduce programming, Apache Spark ecosystems (RDDs, DataFrames), HBase, Hive, Kafka streaming, and data lake architectures.

### Module 5: Analytics & Machine Learning
Statistical foundations, regression and classification models, clustering algorithms, deep learning, NLP, and generative AI applications.

### Module 6: Data Visualization & BI
Tableau dashboards, visualization design principles, business intelligence workflows, and reporting best practices.
