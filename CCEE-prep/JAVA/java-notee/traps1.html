Questions 1-50

Data Types & Variables

1. What is the output?
byte b = 127;
b++;
System.out.println(b);
Show Answer
-128
Byte overflow! 127 + 1 wraps to -128
2. What is the output?
int i = 5/2;
System.out.println(i);
Show Answer
2
Integer division truncates decimal
3. Will this compile?
byte b = 10;
b = b + 1;
Show Answer
No - Compile Error
b + 1 is int. Need explicit cast: b = (byte)(b + 1)
4. Will this compile?
byte b = 10;
b += 1;
Show Answer
Yes - Compiles fine
+= includes implicit cast!
5. What is the output?
char c = 'A';
System.out.println(c + 1);
Show Answer
66
char + int = int (ASCII of 'A' is 65)
6. What is the output?
System.out.println(1 + 2 + "3");
Show Answer
"33"
Left to right: 1+2=3, then 3+"3"="33"
7. What is the output?
System.out.println("1" + 2 + 3);
Show Answer
"123"
"1"+2="12", "12"+3="123"
8. What is the output?
float f = 3.14;
System.out.println(f);
Show Answer
Compile Error
3.14 is double. Need f suffix: 3.14f
9. What is the output?
double d = 5/2;
System.out.println(d);
Show Answer
2.0
5/2 is integer division (2), then assigned to double
10. What is the output?
int x;
System.out.println(x);
Show Answer
Compile Error
Local variables must be initialized before use!

String Comparisons

11. What is the output?
String s1 = "Hello";
String s2 = "Hello";
System.out.println(s1 == s2);
Show Answer
true
String pool - same reference
12. What is the output?
String s1 = new String("Hello");
String s2 = new String("Hello");
System.out.println(s1 == s2);
Show Answer
false
new creates different objects
13. What is the output?
String s1 = "Hello";
String s2 = new String("Hello");
System.out.println(s1.equals(s2));
Show Answer
true
equals() compares content
14. What is the output?
String s = "Hello";
s.concat(" World");
System.out.println(s);
Show Answer
"Hello"
Strings are immutable! concat() returns new String
15. What is the output?
String s = "Hello";
s = s.concat(" World");
System.out.println(s);
Show Answer
"Hello World"
Reassigning reference to new String

Operators

16. What is the output?
int a = 5;
System.out.println(a++ + ++a);
Show Answer
12
5 (post) + 7 (pre) = 12. a becomes 6, then 7
17. What is the output?
int a = 5;
int b = a++;
System.out.println(a + " " + b);
Show Answer
6 5
Post-increment: use then increment
18. What is the output?
int a = 5;
int b = ++a;
System.out.println(a + " " + b);
Show Answer
6 6
Pre-increment: increment then use
19. What is the output?
boolean x = false;
if (x = true) {
    System.out.println("Yes");
} else {
    System.out.println("No");
}
Show Answer
Yes
Assignment (=) not comparison (==)! x becomes true
20. What is the output?
System.out.println(10 > 5 ? 1 : 2 > 1 ? 3 : 4);
Show Answer
1
10>5 is true, returns 1. Second ternary not evaluated
21. What is the output?
int x = 5;
System.out.println(x > 3 & ++x > 3);
Show Answer
true
& (non-short-circuit) evaluates both. x becomes 6
22. What is the output?
int x = 5;
System.out.println(x > 3 && ++x > 10);
System.out.println(x);
Show Answer
false, 6
&& short-circuits, but first was true so second evaluated
23. What is the output?
int x = 5;
System.out.println(x < 3 && ++x > 10);
System.out.println(x);
Show Answer
false, 5
&& short-circuits. First is false, second NOT evaluated

Arrays

24. What is the output?
int[] arr = new int[3];
System.out.println(arr[0]);
Show Answer
0
Array elements have default values
25. What is the output?
String[] arr = new String[3];
System.out.println(arr[0]);
Show Answer
null
Object array elements default to null
26. What is the output?
int[] arr = {1, 2, 3};
System.out.println(arr.length());
Show Answer
Compile Error
length is a field, not method! Use arr.length
27. What is the output?
int[] arr1 = {1, 2, 3};
int[] arr2 = arr1;
arr2[0] = 10;
System.out.println(arr1[0]);
Show Answer
10
Both reference same array!

Control Flow

28. What is the output?
for (int i = 0; i < 5; i++);
{
    System.out.println("Hello");
}
Show Answer
Hello (once)
Semicolon ends for loop! Block executes once
29. What is the output?
int x = 2;
switch(x) {
    case 1: System.out.println("One");
    case 2: System.out.println("Two");
    case 3: System.out.println("Three");
}
Show Answer
Two Three
No break! Fall-through to next cases
30. Will this compile?
long x = 5;
switch(x) {
    case 5: System.out.println("Five");
}
Show Answer
Compile Error
switch doesn't support long!

OOPs

31. What is the output?
class Parent {
    void show() { System.out.println("Parent"); }
}
class Child extends Parent {
    void show() { System.out.println("Child"); }
}
Parent p = new Child();
p.show();
Show Answer
Child
Runtime polymorphism - actual object's method called
32. What is the output?
class Parent {
    static void show() { System.out.println("Parent"); }
}
class Child extends Parent {
    static void show() { System.out.println("Child"); }
}
Parent p = new Child();
p.show();
Show Answer
Parent
Static methods are not overridden! Reference type used
33. What is the output?
class A {
    int x = 10;
}
class B extends A {
    int x = 20;
}
A a = new B();
System.out.println(a.x);
Show Answer
10
Variables are not polymorphic! Reference type used
34. What is the output?
class Test {
    Test() {
        System.out.println("Constructor");
    }
    static {
        System.out.println("Static");
    }
}
new Test();
new Test();
Show Answer
Static Constructor Constructor
Static block runs once when class loaded
35. Can this class be instantiated?
class Test {
    private Test() {}
}
Show Answer
Yes, but only within the class itself
Private constructor prevents external instantiation (Singleton pattern)

Inheritance & Interfaces

36. What is the output?
class Parent {
    Parent() { System.out.println("Parent"); }
}
class Child extends Parent {
    Child() { System.out.println("Child"); }
}
new Child();
Show Answer
Parent Child
super() called implicitly first
37. Will this compile?
class Parent {
    Parent(int x) {}
}
class Child extends Parent {
}
Show Answer
Compile Error
Parent has no no-arg constructor, Child must call super(int)
38. Will this compile?
interface A {
    int x = 10;
}
class Test implements A {
    void method() {
        x = 20;
    }
}
Show Answer
Compile Error
Interface variables are implicitly final!
39. What is the output?
interface A { default void show() { System.out.println("A"); } }
interface B { default void show() { System.out.println("B"); } }
class C implements A, B {
    public void show() { A.super.show(); }
}
new C().show();
Show Answer
A
Diamond problem solved by explicit override calling A.super
40. Will this compile?
abstract class A {
    abstract void show();
    abstract void display();
}
class B extends A {
    void show() {}
}
Show Answer
Compile Error
Must implement ALL abstract methods or be abstract

Exceptions

41. What is the output?
try {
    System.out.println("Try");
    return;
} finally {
    System.out.println("Finally");
}
Show Answer
Try Finally
finally always executes (except System.exit)
42. What is the output?
int getValue() {
    try {
        return 1;
    } finally {
        return 2;
    }
}
System.out.println(getValue());
Show Answer
2
finally return overrides try return!
43. Will this compile?
void method() {
    throw new Exception("Error");
}
Show Answer
Compile Error
Exception is checked - must declare throws or catch
44. Will this compile?
void method() {
    throw new RuntimeException("Error");
}
Show Answer
Yes
RuntimeException is unchecked - no declaration needed
45. What is the output?
try {
    System.out.println("Try");
} catch (Exception e) {
    System.out.println("Catch");
} finally {
    System.out.println("Finally");
}
Show Answer
Try Finally
No exception, catch skipped
