Collections

51. What is the output?
List<Integer> list = new ArrayList<>();
list.add(1);
list.add(2);
list.remove(1);
System.out.println(list);
Show Answer
[1]
remove(1) removes at INDEX 1, not value 1!
52. What is the output?
List<Integer> list = new ArrayList<>();
list.add(1);
list.add(2);
list.remove(Integer.valueOf(1));
System.out.println(list);
Show Answer
[2]
remove(Object) removes by VALUE
53. What is the output?
Set<String> set = new HashSet<>();

Show Answer
2

Map<String, Integer> map = new HashMap<>();

55. What is the output?

60. What is the output?

Threads

61. What is wrong?
class MyThread extends Thread {
    public void run() { System.out.println("Running"); }
}
MyThread t = new MyThread();
t.run();
Show Answer
No new thread created!
Call start() not run()! run() executes in current thread
62. What is the output?
Thread t = new Thread(() -> {
    try { Thread.sleep(1000); } catch(Exception e) {}
    System.out.println("Thread");
});
t.start();
System.out.println("Main");
Show Answer
Main Thread (usually)
Main doesn't wait for t. Order depends on scheduling
63. What is the output?
Thread t = new Thread(() -> System.out.println("Thread"));
t.start();
t.start();
Show Answer
IllegalThreadStateException
Cannot start a thread twice!
64. What is the output?
synchronized void method1() { method2(); }
synchronized void method2() { }
Show Answer
Works fine - no deadlock
Java allows reentrant synchronization on same lock
65. What happens?
Object lock = new Object();
lock.wait();
Show Answer
IllegalMonitorStateException
wait() must be called from synchronized block!

Lambda & Streams

66. What is the output?
List<Integer> list = Arrays.asList(1, 2, 3);
list.stream().filter(n -> n > 1);
System.out.println(list);
Show Answer
[1, 2, 3]
Stream operations don't modify original. Need terminal op!
67. What is the output?
Stream<Integer> s = Stream.of(1, 2, 3);
s.forEach(System.out::println);
s.forEach(System.out::println);
Show Answer
IllegalStateException on second forEach
Stream can only be consumed once!
68. What is the output?
List<String> list = Arrays.asList("a", "b", "c");
long count = list.stream()
    .filter(s -> s.length() > 0)
    .peek(System.out::println)
    .count();
System.out.println(count);
Show Answer
3 (but peek may not print!)
Since Java 9, count() may skip intermediate ops if size known
69. Will this compile?
Runnable r = () -> System.out.println("Hello");
Callable c = () -> System.out.println("Hello");
Show Answer
Callable won't compile
Callable.call() must return a value!
70. What is the output?
int x = 10;
Runnable r = () -> System.out.println(x);
x = 20;
r.run();
Show Answer
Compile Error
Lambda can only capture effectively final variables!

More OOPs

71. What is the output?
class Parent {
    void show() throws IOException {}
}
class Child extends Parent {
    void show() throws Exception {}
}
Show Answer
Compile Error
Overriding method cannot throw broader exception!
72. What is the output?
class Parent {
    private void show() { System.out.println("Parent"); }
}
class Child extends Parent {
    public void show() { System.out.println("Child"); }
}
Parent p = new Child();
p.show();
Show Answer
Compile Error
Parent.show() is private, not accessible via Parent reference!
73. What is the output?
abstract class A {
    A() { show(); }
    abstract void show();
}
class B extends A {
    int x = 10;
    void show() { System.out.println(x); }
}
new B();
Show Answer
0
Constructor called before instance var initialized!
74. What is the output?
interface A { int x = 1; }
interface B { int x = 2; }
class C implements A, B {
    void show() { System.out.println(x); }
}
Show Answer
Compile Error
Ambiguous reference! Must use A.x or B.x
75. Will this compile?
class Outer {
    int x = 10;
    static class Inner {
        void show() { System.out.println(x); }
    }
}
Show Answer
Compile Error
Static inner class cannot access non-static outer members!

More Exceptions

76. What is the output?
try {
    try {
        throw new Exception();
    } finally {
        System.out.println("Inner finally");
    }
} catch (Exception e) {
    System.out.println("Outer catch");
}
Show Answer
Inner finally Outer catch
Exception propagates after finally runs
77. What is the output?
try {
    throw new RuntimeException();
} catch (RuntimeException e) {
    throw new RuntimeException();
} finally {
    System.out.println("Finally");
}
Show Answer
Finally, then RuntimeException thrown
finally runs even if catch throws
78. What is the output?
try {
    System.exit(0);
} finally {
    System.out.println("Finally");
}
Show Answer
Nothing (program terminated)
System.exit() prevents finally from running!
79. Will this compile?

    // handle
}
Show Answer
Yes
Specific exception before general - correct order
80. Will this compile?
try {

Wrapper Classes & Boxing

81. What is the output?
Integer a = new Integer(5);
Integer b = new Integer(5);
System.out.println(a == b);
Show Answer
false
new creates different objects, bypasses cache
82. What is the output?
Integer a = 1000;
int b = 1000;
System.out.println(a == b);
Show Answer
true
Unboxing occurs, values compared
83. What is the output?
Integer a = null;
int b = a;
Show Answer
NullPointerException
Cannot unbox null!
84. What is the output?
Double d1 = 1.0;
Double d2 = 1.0;
System.out.println(d1 == d2);
Show Answer
false
Double has no cache unlike Integer!
85. What is the output?
System.out.println(Integer.valueOf("10", 2));
Show Answer
2
Second arg is radix. "10" in binary = 2

Method Signatures

86. Will this overload?

void method(int[] a) {}
Show Answer
Compile Error
Varargs int... is same as int[] - duplicate method!
87. What is called?
void method(int a, int b) { System.out.println(1); }
void method(int... a) { System.out.println(2); }
method(1, 2);
Show Answer
1
Exact match preferred over varargs
88. Will this compile?
void method(int... a, int b) {}
Show Answer
Compile Error
Varargs must be last parameter!
89. What is the output?

Show Answer
String
Most specific type selected
90. What is the output?
void method(String s) { System.out.println("String"); }
void method(Integer i) { System.out.println("Integer"); }
method(null);
Show Answer
Compile Error
Ambiguous - null could be either type!
