String Class

String s = "Hello";

// Methods
s.length();              // 5
s.charAt(0);             // 'H'
s.substring(1, 4);       // "ell"
s.toUpperCase();         // "HELLO"
s.toLowerCase();         // "hello"

s.contains("ell");       // true
s.startsWith("He");      // true
s.endsWith("lo");        // true
s.indexOf("l");          // 2
s.lastIndexOf("l");      // 3
s.equals("Hello");       // true (content)
s.equalsIgnoreCase("HELLO"); // true

// String Pool
String s1 = "Hello";
String s2 = "Hello";
s1 == s2  // true (same pool object)

String s3 = new String("Hello");
s1 == s3  // false (different objects)
s1.equals(s3)  // true (same content)

sb.insert(5, ",");       // "Hello, World"
sb.delete(5, 6);         // "Hello World"
sb.reverse();            // "dlroW olleH"
sb.toString();           // Convert to String
StringBuilder StringBuffer
Not synchronized Synchronized (thread-safe)
Faster Slower

3. Lambda Expressions (Java 8+)

What is Lambda?

Anonymous function that implements functional interface. Enables functional programming in Java.

Syntax

// Full syntax
(parameters) -> { statements; }

// Shortened forms
(a, b) -> a + b              // Expression body
a -> a * 2                   // Single parameter
() -> System.out.println()   // No parameters

Functional Interface

@FunctionalInterface
interface Calculator {
    int calculate(int a, int b);  // Single abstract method
}

// Lambda implementation
Calculator add = (a, b) -> a + b;
Calculator sub = (a, b) -> a - b;

System.out.println(add.calculate(5, 3));  // 8

Built-in Functional Interfaces

Interface Method Purpose
Predicate<T> test(T) Returns boolean
Function<T,R> apply(T) Returns R
Consumer<T> accept(T) Returns void
Supplier<T> get() Returns T
BiFunction<T,U,R> apply(T,U) Two inputs, returns R 
// Predicate - test condition
Predicate isEven = n -> n % 2 == 0;
isEven.test(4);  // true

// Function - transform
Function length = s -> s.length();
length.apply("Hello");  // 5

// Consumer - consume value
Consumer printer = s -> System.out.println(s);
printer.accept("Hello");

// Supplier - supply value
Supplier random = () -> Math.random();
random.get();  // 0.xxx

Method References

// Static method
Function parse = Integer::parseInt;

// Instance method
Consumer print = System.out::println;

// Constructor
Supplier newList = ArrayList::new;

// Types:
// ClassName::staticMethod
// object::instanceMethod
// ClassName::instanceMethod
// ClassName::new
MCQ Tip: Functional interface = exactly ONE abstract method. Can have default/static methods.
4. Streams API (Java 8+)

What is a Stream?

Sequence of elements supporting functional-style operations. Does NOT store data, processes on-demand.

Creating Streams

// From Collection
List list = Arrays.asList("a", "b", "c");
Stream stream = list.stream();

// From Array
Stream arrStream = Arrays.stream(new Integer[]{1, 2, 3});

// Using Stream.of()
Stream stream2 = Stream.of("a", "b", "c");

// Infinite streams
Stream infinite = Stream.iterate(0, n -> n + 1);

Intermediate Operations (Lazy)

list.stream()
    .filter(s -> s.length() > 3)     // Keep matching
    .map(s -> s.toUpperCase())       // Transform
    .sorted()                         // Sort
    .distinct()                       // Remove duplicates
    .limit(10)                        // First n elements
    .skip(5);                         // Skip first n

Terminal Operations (Execute)

list.stream().forEach(System.out::println);  // Print each
list.stream().collect(Collectors.toList());  // To List
list.stream().toArray();                      // To array
list.stream().count();                        // Count elements
list.stream().findFirst();                    // First element
list.stream().anyMatch(s -> s.isEmpty());    // Any match?
list.stream().allMatch(s -> s.length() > 0); // All match?
list.stream().noneMatch(s -> s.isEmpty());   // None match?
list.stream().reduce((a, b) -> a + b);       // Combine all

Common Patterns

// Filter and collect
List evens = numbers.stream()
    .filter(n -> n % 2 == 0)
    .collect(Collectors.toList());

// Map and collect
List names = persons.stream()
    .map(Person::getName)
    .collect(Collectors.toList());

// Sum
int sum = numbers.stream()
    .mapToInt(Integer::intValue)
    .sum();

// Group by
Map> byCity = persons.stream()
    .collect(Collectors.groupingBy(Person::getCity));

// Join strings
String result = list.stream()
    .collect(Collectors.joining(", "));

Parallel Streams

list.parallelStream()
    .filter(...)
    .collect(...);
    
// Or convert
list.stream().parallel();
Key: Streams are lazy - intermediate ops don't execute until terminal op is called!
5. JDBC API

What is JDBC?

Java Database Connectivity - API to connect and execute queries on databases.

JDBC Architecture

Java Application
      ↓
JDBC API (java.sql)
      ↓
JDBC Driver Manager
      ↓
JDBC Driver (vendor-specific)
      ↓
Database

Steps to Connect

// 1. Load driver (optional in JDBC 4.0+)
Class.forName("com.mysql.cj.jdbc.Driver");

// 2. Get connection
Connection conn = DriverManager.getConnection(
    "jdbc:mysql://localhost:3306/mydb",
    "username",
    "password"
);

// 3. Create statement
Statement stmt = conn.createStatement();

// 4. Execute query
ResultSet rs = stmt.executeQuery("SELECT * FROM users");

// 5. Process results
while (rs.next()) {
    int id = rs.getInt("id");
    String name = rs.getString("name");
}

// 6. Close resources
rs.close();
stmt.close();
conn.close();

Statement Types

Type Use Case
Statement Simple SQL, no parameters
PreparedStatement Parameterized, precompiled
CallableStatement Stored procedures

PreparedStatement

String sql = "INSERT INTO users (name, age) VALUES (?, ?)";
PreparedStatement pstmt = conn.prepareStatement(sql);
pstmt.setString(1, "John");
pstmt.setInt(2, 25);
pstmt.executeUpdate();

// For SELECT
ResultSet rs = pstmt.executeQuery();

Execute Methods

Method Use For Returns
executeQuery() SELECT ResultSet
executeUpdate() INSERT/UPDATE/DELETE int (affected rows)
execute() Any SQL boolean

Transaction Management

try {
    conn.setAutoCommit(false);
    
    stmt.executeUpdate("UPDATE accounts SET balance = balance - 100 WHERE id = 1");
    stmt.executeUpdate("UPDATE accounts SET balance = balance + 100 WHERE id = 2");
    
    conn.commit();
} catch (SQLException e) {
    conn.rollback();
}

Try-with-resources

try (Connection conn = DriverManager.getConnection(url, user, pass);
     PreparedStatement pstmt = conn.prepareStatement(sql);
     ResultSet rs = pstmt.executeQuery()) {
    
    while (rs.next()) {
        // process
    }
} // Auto-closed!
MCQ Tip: executeQuery() for SELECT. executeUpdate() for INSERT/UPDATE/DELETE!
