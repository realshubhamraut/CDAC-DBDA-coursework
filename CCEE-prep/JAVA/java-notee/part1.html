Java Programming Notes
Part 1: JVM, Data Types & Operators

1. Introduction to Java Virtual Machine (JVM)

What is JVM?

JVM (Java Virtual Machine) is an abstract machine that provides a runtime environment to execute Java bytecode. It's part of JRE (Java Runtime Environment).

JDK vs JRE vs JVM

Component Description Contains
JDK Java Development Kit JRE + Development Tools (javac, jar, etc.)
JRE Java Runtime Environment JVM + Libraries
JVM Java Virtual Machine Executes bytecode

JVM Architecture

  • Class Loader - Loads .class files into memory
  • Method Area - Stores class metadata, static variables, constant pool
  • Heap - Runtime data area where objects are allocated
  • Stack - Stores local variables and method calls (per thread)
  • PC Register - Address of current executing instruction
  • Native Method Stack - For native (non-Java) methods
  • Execution Engine - Executes bytecode (Interpreter + JIT Compiler)

How Java Code Executes

Source Code (.java) 
    ↓ javac (compiler)
Bytecode (.class) 
    ↓ JVM
Machine Code (executed)

Key Features of JVM

  • Platform Independent - Write Once, Run Anywhere (WORA)
  • Memory Management - Automatic Garbage Collection
  • Security - Bytecode verification, sandbox execution
  • Multithreading - Built-in thread support

Class Loader Types

Type Loads From
Bootstrap rt.jar (core Java classes)
Extension ext folder (jre/lib/ext)
Application/System Classpath

JIT Compiler

Just-In-Time compiler converts bytecode to native machine code at runtime for better performance. Frequently executed code (hot spots) are compiled to native code.

MCQ Tip: JVM is platform-dependent, but bytecode is platform-independent!
2. Data Types in Java

Two Categories

  • Primitive Types - 8 types (stored in stack)
  • Reference Types - Objects, Arrays, Interfaces (stored in heap)

Primitive Data Types

Type Size Default Range
byte 1 byte 0 -128 to 127
short 2 bytes 0 -32,768 to 32,767
int 4 bytes 0 -2³¹ to 2³¹-1
long 8 bytes 0L -2⁶³ to 2⁶³-1
float 4 bytes 0.0f ~±3.4E38
double 8 bytes 0.0d ~±1.7E308
char 2 bytes '\u0000' 0 to 65,535
boolean ~1 bit false true/false

Literals

// Integer literals
int decimal = 100;
int octal = 0144;      // prefix 0
int hex = 0x64;        // prefix 0x
int binary = 0b1100100; // prefix 0b (Java 7+)

// Long literal
long l = 100L;         // suffix L or l

// Float/Double
float f = 3.14f;       // suffix f required
double d = 3.14;       // default is double
double d2 = 3.14d;

// Char literals
char c1 = 'A';
char c2 = 65;          // ASCII value
char c3 = '\u0041';    // Unicode

// Underscore in numbers (Java 7+)
int million = 1_000_000;

Type Casting

// Widening (Implicit) - automatic
byte → short → int → long → float → double
int i = 100;
long l = i;    // OK

// Narrowing (Explicit) - manual cast required
double d = 100.5;
int i = (int) d;  // i = 100 (truncated)

// char to int (widening)
char c = 'A';
int i = c;     // i = 65

Wrapper Classes

Primitive Wrapper
byte Byte
short Short
int Integer
long Long
float Float
double Double
char Character
boolean Boolean 
// Autoboxing (primitive → wrapper)
Integer obj = 100;  // auto-converted

// Unboxing (wrapper → primitive)
int i = obj;        // auto-converted

// Parsing strings
int i = Integer.parseInt("100");
double d = Double.parseDouble("3.14");

String (Reference Type)

String s1 = "Hello";           // String pool
String s2 = new String("Hello"); // Heap

s1 == s2       // false (different objects)
s1.equals(s2)  // true (same content)

// String is immutable!
String s = "Hello";
s.concat(" World");  // original s unchanged
s = s.concat(" World"); // now s = "Hello World"
MCQ Tip: char in Java is 2 bytes (Unicode), not 1 byte like C!
3. Variables

Variable Types

Type Declared In Scope Default Value
Local Method/Block Method/Block None (must initialize)
Instance Class (outside method) Object lifetime Type default (0, null, false)
Static/Class Class with static Class lifetime Type default 
class Example {
    // Instance variable
    int instanceVar = 10;
    
    // Static variable
    static int staticVar = 20;
    
    void method() {
        // Local variable (must initialize!)
        int localVar = 30;
    }
}

Variable Naming Rules

  • Can contain letters, digits, underscore, dollar sign
  • Cannot start with a digit
  • Cannot be a reserved keyword
  • Case-sensitive (myVar ≠ MyVar)

final Keyword

final int CONSTANT = 100;
CONSTANT = 200;  // ERROR! Cannot reassign

final class FinalClass {}  // Cannot be extended
final void method() {}     // Cannot be overridden
Key: Local variables don't have default values - must initialize before use!
4. Operators

Arithmetic Operators

+   Addition
-   Subtraction

/   Division
%   Modulus (remainder)

// Integer division
5 / 2     // 2 (truncated)
5.0 / 2   // 2.5

// Increment/Decrement
i++  // post-increment (use then increment)
++i  // pre-increment (increment then use)
i--  // post-decrement

Relational Operators

==   Equal to
!=   Not equal to
>    Greater than
<    Less than
>=   Greater than or equal
<=   Less than or equal

Logical Operators

&&   AND (short-circuit)
||   OR (short-circuit)
!    NOT

&    AND (no short-circuit, evaluates both)
|    OR (no short-circuit, evaluates both)
^    XOR

Short-Circuit Evaluation

// && stops if first is false
if (false && method()) {}  // method() NOT called

// || stops if first is true
if (true || method()) {}   // method() NOT called

Bitwise Operators

&    Bitwise AND
|    Bitwise OR
^    Bitwise XOR
~    Bitwise NOT (complement)
<<   Left shift
>>   Right shift (signed)
>>>  Unsigned right shift

Assignment Operators

=    Simple assignment
+=   Add and assign
-=   Subtract and assign
*=   Multiply and assign
/=   Divide and assign
%=   Modulus and assign
&=, |=, ^=, <<=, >>=, >>>=

Ternary Operator

condition ? value_if_true : value_if_false

int max = (a > b) ? a : b;

instanceof Operator

String s = "Hello";
if (s instanceof String) {   // true
    System.out.println("It's a String");
}

if (s instanceof Object) {   // true (all inherit Object)
    System.out.println("It's an Object");
}

5. Control Statements

if-else

if (condition) {
    // code
} else if (condition2) {
    // code
} else {
    // code
}

switch Statement

switch (expression) {
    case value1:
        // code
        break;
    case value2:
        // code
        break;
    default:
        // code
}

// Switch with String (Java 7+)
switch (day) {
    case "Monday":
        break;
}

Switch Expression (Java 12+)

String result = switch (day) {
    case "Mon", "Tue", "Wed" -> "Weekday";
    case "Sat", "Sun" -> "Weekend";
    default -> "Unknown";
};

for Loop

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// Enhanced for (for-each)
int[] arr = {1, 2, 3};
for (int num : arr) {
    System.out.println(num);
}

while Loop

while (condition) {
    // code
}

do-while Loop

do {
    // code (executes at least once)
} while (condition);

break and continue

// break - exit loop
for (int i = 0; i < 10; i++) {
    if (i == 5) break;  // exits at 5
}

// continue - skip iteration
for (int i = 0; i < 10; i++) {
    if (i == 5) continue;  // skips 5
    System.out.println(i);
}

// Labeled break
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break outer;  // exits both loops
    }
}
Key: switch works with: byte, short, int, char, String (Java 7+), enum. NOT long, float, double!
6. Arrays

Declaration and Initialization

// Declaration
int[] arr;      // preferred
int arr2[];     // valid but not preferred

// Initialization
arr = new int[5];
int[] arr3 = new int[5];
int[] arr4 = {1, 2, 3, 4, 5};
int[] arr5 = new int[]{1, 2, 3};

Default Values

Type Default
int, short, byte, long 0
float, double 0.0
char '\u0000'
boolean false
Object references null

Array Properties

int[] arr = {1, 2, 3, 4, 5};

arr.length      // 5 (property, not method!)
arr[0]          // 1 (first element)
arr[arr.length-1]  // 5 (last element)

Multi-dimensional Arrays

// 2D array
int[][] matrix = new int[3][4];
int[][] matrix2 = {{1,2}, {3,4}, {5,6}};

matrix[0][1] = 10;  // row 0, col 1

// Jagged array (different row lengths)
int[][] jagged = new int[3][];
jagged[0] = new int[2];
jagged[1] = new int[4];
jagged[2] = new int[3];

Array Iteration

// Traditional for
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}

// Enhanced for
for (int num : arr) {
    System.out.println(num);
}

Arrays Class (java.util.Arrays)

import java.util.Arrays;

Arrays.sort(arr);           // Sort array
Arrays.binarySearch(arr, 3); // Find element
Arrays.fill(arr, 0);        // Fill with value
Arrays.equals(arr1, arr2);  // Compare arrays
Arrays.toString(arr);       // "[1, 2, 3, 4, 5]"
Arrays.copyOf(arr, 10);     // Copy with new length
MCQ Tip: length is a property for arrays, length() is a method for String!
