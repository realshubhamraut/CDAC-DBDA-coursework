Advanced OOPs

101. What is the output?
class A { static int x = 10; }
class B extends A { static int x = 20; }
System.out.println(B.x);
System.out.println(((A)new B()).x);
Show Answer
20, 10
Static variables use reference type, not object type
102. What is the output?
final class A {}
class B extends A {}
Show Answer
Compile Error
Cannot extend final class!
103. What is the output?
class A {
    void show(int x) { System.out.println("int"); }
    void show(Integer x) { System.out.println("Integer"); }
}
new A().show(5);
Show Answer
int
Exact match (primitive) preferred over autoboxing
104. Can this class be instantiated?

Show Answer

Abstract class cannot be instantiated even without abstract methods
105. What is the output?
class Outer {
    int x = 10;
    class Inner {
        int x = 20;
        void show() {
            int x = 30;
            System.out.println(x);
            System.out.println(this.x);
            System.out.println(Outer.this.x);
        }
    }
}
new Outer().new Inner().show();
Show Answer
30, 20, 10
Local, inner class, outer class references
