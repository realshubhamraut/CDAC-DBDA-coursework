FunctionPurposeExample

6. Manipulating Data Frames

Creating Data Frames

df <- data.frame(
  col1 = c(1, 2, 3),
  col2 = c("a", "b", "c"),
  stringsAsFactors = FALSE
)

Accessing Data

df$column           # By column name
df[, "column"]      # By column name (alternative)
df[, 1]             # By column index
df[1, ]             # First row
df[1:3, ]           # Rows 1-3
df[c(1,3), ]        # Rows 1 and 3
df[df$age > 25, ]   # Conditional selection

Adding/Modifying Columns

df$new_col <- c(1, 2, 3)              # Add column
df["new_col"] <- c(1, 2, 3)           # Alternative
df$col1 <- df$col1 * 2                # Modify column
df <- transform(df, new=col1+col2)    # Transform

Sorting Data

df[order(df$age), ]                   # Sort by age (ascending)
df[order(-df$age), ]                  # Sort descending
df[order(df$name, df$age), ]          # Sort by multiple columns

Extracting Subsets

subset(df, age > 25)                  # Filter rows
subset(df, age > 25, select=c(name))  # Filter + select columns
df[df$age > 25, c("name", "age")]     # Base R method

Combining Data Frames

rbind(df1, df2)     # Row bind (stack vertically)
cbind(df1, df2)     # Column bind (side by side)

Merging Data Frames

merge(df1, df2, by="id")                      # Inner join
merge(df1, df2, by="id", all=TRUE)            # Full outer join
merge(df1, df2, by="id", all.x=TRUE)          # Left join
merge(df1, df2, by="id", all.y=TRUE)          # Right join
merge(df1, df2, by.x="id1", by.y="id2")       # Different column names

Reshaping Data

# Wide to Long
reshape(df, direction="long", varying=list(c("var1","var2")))

# Using tidyr (modern approach)
library(tidyr)
pivot_longer(df, cols=c(col1, col2), names_to="name", values_to="value")
pivot_wider(df, names_from=name, values_from=value)
Remember: rbind() = rows, cbind() = columns, merge() = SQL-like joins

11. Queuing Theory

Basic Concepts

  • Queue: Waiting line for service
  • Arrival Rate (λ): Average arrivals per time unit
  • Service Rate (μ): Average services per time unit
  • Traffic Intensity (ρ): λ/μ (must be < 1 for stable queue)

Kendall Notation: A/B/c/K/N/D

  • A: Arrival process (M=Markovian/Poisson, D=Deterministic, G=General)
  • B: Service distribution (M, D, G)
  • c: Number of servers
  • K: System capacity (default: infinite)
  • N: Population size (default: infinite)
  • D: Queue discipline (FIFO, LIFO, SIRO)

M/M/1 Queue Formulas

MetricFormulaMeaning
ρλ/μUtilization
Lλ/(μ-λ)Avg customers in system
Lqλ²/[μ(μ-λ)]Avg customers in queue
W1/(μ-λ)Avg time in system
Wqλ/[μ(μ-λ)]Avg time in queue
P₀1-ρProbability of empty system
Pn(1-ρ)ρⁿProbability of n customers

R Implementation

# M/M/1 Queue calculations
lambda <- 6  # Arrival rate
mu <- 10     # Service rate
rho <- lambda/mu
L <- lambda/(mu-lambda)
Lq <- lambda^2/(mu*(mu-lambda))
W <- 1/(mu-lambda)
Wq <- lambda/(mu*(mu-lambda))

# queueing package
library(queueing)
i <- NewInput.MM1(lambda=6, mu=10)
m <- QueueingModel(i)
summary(m)
Remember: For stable queue, ρ = λ/μ must be less than 1.
