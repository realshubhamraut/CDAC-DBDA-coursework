1. Python Basics

What is Python?

High-level, interpreted, dynamically-typed programming language. Known for readability and simplicity.

Key Features

  • Interpreted - No compilation, runs line by line
  • Dynamically Typed - No need to declare variable types
  • Indentation-based - Uses whitespace for blocks (no braces)
  • Case Sensitive - name ≠ Name

Variables & Assignment

# No declaration needed
x = 10          # int
y = 3.14        # float
name = "John"   # str
flag = True     # bool

# Multiple assignment
a, b, c = 1, 2, 3
x = y = z = 0

2. Conditional Statements (if, if-else, nested)

if Statement

if condition:
    # code (must be indented)

if-else

if condition:
    # if block
else:
    # else block

if-elif-else

if condition1:
    # code
elif condition2:
    # code
elif condition3:
    # code
else:
    # code

Nested if-else

if condition1:
    if condition2:
        # nested code
    else:
        # code
else:
    # code

Ternary Operator (One-liner if-else)

result = value_if_true if condition else value_if_false

# Example
x = 10
msg = "Even" if x % 2 == 0 else "Odd"

Truthy and Falsy Values

Falsy (evaluates to False) Truthy (evaluates to True)
False True
None Non-zero numbers
0, 0.0 Non-empty strings
"", '', """""" (empty string) Non-empty collections
[], (), {}, set() (empty) Objects 
# Truthy/Falsy in conditions
if []:          # False (empty list)
    print("Yes")

if [1, 2]:      # True (non-empty list)
    print("Yes")

if "":          # False (empty string)
    print("Yes")

if "hello":     # True
    print("Yes")
MCQ Tip: Empty collections, 0, None, and empty strings are Falsy. Everything else is Truthy.
3. Loops (for, while, nested)

for Loop

# Iterate over sequence
for item in sequence:
    # code

# Examples
for i in range(5):        # 0,1,2,3,4
    print(i)

for i in range(2, 6):     # 2,3,4,5
    print(i)

for i in range(0, 10, 2): # 0,2,4,6,8 (step=2)
    print(i)

for char in "hello":      # h,e,l,l,o
    print(char)

for item in [1, 2, 3]:    # iterating list
    print(item)

while Loop

while condition:
    # code
    # must update condition

# Example
i = 0
while i < 5:
    print(i)
    i += 1

Nested Loops

for i in range(3):
    for j in range(3):
        print(i, j)

# Output: (0,0)(0,1)(0,2)(1,0)...

Loop with else

# else executes if loop completes without break
for i in range(5):
    print(i)
else:
    print("Loop completed!")  # This runs

for i in range(5):
    if i == 3:
        break
else:
    print("Won't print")  # Skipped due to break

enumerate() and zip()

# enumerate - get index and value
for idx, val in enumerate(['a', 'b', 'c']):
    print(idx, val)  # 0 a, 1 b, 2 c

# zip - iterate multiple sequences
for x, y in zip([1,2,3], ['a','b','c']):
    print(x, y)  # 1 a, 2 b, 3 c

range() Function

range(stop)           # 0 to stop-1
range(start, stop)    # start to stop-1
range(start, stop, step)  # with step

list(range(5))        # [0, 1, 2, 3, 4]
list(range(5, 0, -1)) # [5, 4, 3, 2, 1]
Remember: range() end is exclusive! range(5) gives 0-4, not 0-5
4. Control Structures (break, continue, pass)

break

Exits the loop completely.

for i in range(10):
    if i == 5:
        break       # exits loop
    print(i)        # prints 0,1,2,3,4

continue

Skips current iteration, continues to next.

for i in range(5):
    if i == 2:
        continue    # skip 2
    print(i)        # prints 0,1,3,4

pass

Does nothing - placeholder for empty blocks.

# Empty function/class placeholder
def my_function():
    pass            # avoids error

class MyClass:
    pass

# Empty loop
for i in range(5):
    pass            # do nothing

Comparison

Keyword Effect
break Exit loop entirely
continue Skip to next iteration
pass Do nothing (placeholder)
MCQ Tip: break also skips the else clause of a loop. continue does not.
5. Strings

Creating Strings

s = "Hello"
s = 'Hello'
s = """Multi
line"""
s = '''Also
multiline'''

String Immutability

s = "hello"
s[0] = "H"  # ERROR! Strings are immutable
s = "Hello" # OK - reassignment creates new string

Accessing Characters (Indexing)

s = "Python"
s[0]    # 'P' (first)
s[-1]   # 'n' (last)
s[-2]   # 'o' (second last)

String Slicing

s = "Python"
s[start:end]      # start to end-1
s[start:end:step] # with step

s[0:3]    # "Pyt"
s[:3]     # "Pyt" (from start)
s[3:]     # "hon" (to end)
s[::2]    # "Pto" (every 2nd char)
s[::-1]   # "nohtyP" (reverse)

String Operations

s1 + s2         # Concatenation
s * 3           # Repetition "aaa"
"a" in s        # Membership check
len(s)          # Length

String Methods

Method Purpose Example
upper() Uppercase "hi".upper() → "HI"
lower() Lowercase "HI".lower() → "hi"
strip() Remove whitespace " hi ".strip() → "hi"
split() Split to list "a,b".split(",") → ['a','b']
join() Join list ",".join(['a','b']) → "a,b"
replace() Replace "hi".replace("i","o") → "ho"
find() Find index (-1 if not found) "hello".find("l") → 2
index() Find index (error if not found) "hello".index("l") → 2

endswith() Check suffix "hello".endswith("lo") → True
isdigit() All digits? "123".isdigit() → True
isalpha() All letters? "abc".isalpha() → True
isalnum() Alphanumeric? "abc123".isalnum() → True

String Formatting

# f-strings (Python 3.6+)
name = "John"
age = 25
print(f"Name: {name}, Age: {age}")
print(f"2 + 2 = {2+2}")

# format() method
"Name: {}, Age: {}".format(name, age)
"Name: {0}, Age: {1}".format(name, age)

# % formatting (old style)
"Name: %s, Age: %d" % (name, age)
Key: find() returns -1 if not found. index() raises ValueError.
6. Lists

Creating Lists

lst = [1, 2, 3, 4, 5]
lst = list("abc")       # ['a', 'b', 'c']
lst = list(range(5))    # [0, 1, 2, 3, 4]
lst = []                # empty list
lst = [0] * 5           # [0, 0, 0, 0, 0]

List Characteristics

  • Ordered - maintains insertion order
  • Mutable - can modify after creation
  • Allows duplicates
  • Heterogeneous - can mix types

Accessing Elements

lst = [10, 20, 30, 40, 50]
lst[0]      # 10 (first)
lst[-1]     # 50 (last)
lst[1:3]    # [20, 30] (slice)
lst[::-1]   # [50, 40, 30, 20, 10] (reverse)

Modifying Lists

lst[0] = 100        # Change element
lst[1:3] = [5, 6]   # Replace slice

List Methods

Method Purpose Returns
append(x) Add to end None
insert(i, x) Insert at index None
extend(lst) Add all from iterable None
remove(x) Remove first x None (error if not found)
pop() Remove & return last Removed element
pop(i) Remove & return at index Removed element
clear() Remove all None
index(x) Find index of x Index (error if not found)
count(x) Count occurrences int
sort() Sort in place None
reverse() Reverse in place None
copy() Shallow copy New list 
# Examples
lst = [3, 1, 2]
lst.append(4)       # [3, 1, 2, 4]
lst.insert(0, 0)    # [0, 3, 1, 2, 4]
lst.extend([5, 6])  # [0, 3, 1, 2, 4, 5, 6]
lst.pop()           # returns 6, lst = [0, 3, 1, 2, 4, 5]
lst.remove(3)       # [0, 1, 2, 4, 5]
lst.sort()          # [0, 1, 2, 4, 5]
lst.reverse()       # [5, 4, 2, 1, 0]

List Comprehension

# Basic syntax
[expression for item in iterable]
[expression for item in iterable if condition]

# Examples
squares = [x**2 for x in range(5)]      # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x%2==0] # [0, 2, 4, 6, 8]
upper = [s.upper() for s in ['a','b']]  # ['A', 'B']

Nested Lists (2D)

matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
matrix[0]       # [1, 2, 3] (first row)
matrix[0][1]    # 2 (row 0, col 1)

List Functions

len(lst)        # Length
sum(lst)        # Sum of elements
min(lst)        # Minimum
max(lst)        # Maximum
sorted(lst)     # Returns new sorted list (original unchanged)
list(reversed(lst))  # Returns reversed iterator
MCQ Tip: sort() modifies in place & returns None. sorted() returns new list.
7. Tuples

Creating Tuples

t = (1, 2, 3)
t = 1, 2, 3         # parentheses optional
t = tuple([1,2,3])  # from list
t = ()              # empty tuple
t = (1,)            # single element (comma required!)
t = (1)             # NOT a tuple, just int

Tuple Characteristics

  • Ordered - maintains order
  • Immutable - cannot modify after creation
  • Allows duplicates
  • Faster than lists

Accessing Elements

t = (10, 20, 30, 40)
t[0]        # 10
t[-1]       # 40
t[1:3]      # (20, 30)

# t[0] = 100  # ERROR! Immutable

Tuple Methods

t.count(x)   # Count occurrences of x
t.index(x)   # Find index of x

Tuple Unpacking

t = (1, 2, 3)
a, b, c = t     # a=1, b=2, c=3

# Swap using tuples
a, b = b, a

# Extended unpacking
a, *rest = (1, 2, 3, 4)  # a=1, rest=[2,3,4]
*start, last = (1, 2, 3) # start=[1,2], last=3

Tuple vs List

Tuple List
Immutable Mutable
() parentheses [] brackets
Faster Slower
Can be dict key Cannot be dict key
Less memory More memory
Key: Single element tuple needs comma: (1,) not (1)
8. Dictionaries

Creating Dictionaries

d = {"name": "John", "age": 25}
d = dict(name="John", age=25)
d = {}                  # empty dict
d = dict()              # empty dict

Dictionary Characteristics

  • Key-Value pairs
  • Keys must be immutable (str, int, tuple)
  • Keys are unique
  • Ordered (Python 3.7+)
  • Mutable

Accessing Values

d = {"name": "John", "age": 25}
d["name"]           # "John"
d["city"]           # KeyError!
d.get("city")       # None (no error)
d.get("city", "NA") # "NA" (default)

Modifying Dictionaries

d["age"] = 30           # Update
d["city"] = "NYC"       # Add new key
del d["age"]            # Delete key

Dictionary Methods

Method Purpose
keys() Return all keys
values() Return all values
items() Return key-value pairs
get(key, default) Get value safely
pop(key) Remove & return value
popitem() Remove last item
update(dict2) Merge dictionaries
clear() Remove all
copy() Shallow copy
setdefault(k, v) Get or set default 
# Iterating
for key in d:
    print(key, d[key])

for key, value in d.items():
    print(key, value)

Dictionary Comprehension

{key: value for item in iterable}

# Examples
squares = {x: x**2 for x in range(5)}
# {0:0, 1:1, 2:4, 3:9, 4:16}

# Filter
evens = {k:v for k,v in d.items() if v > 10}

Nested Dictionaries

students = {
    "s1": {"name": "John", "age": 20},
    "s2": {"name": "Jane", "age": 22}
}
students["s1"]["name"]  # "John"
MCQ Tip: Lists cannot be dictionary keys (mutable), but tuples can (immutable).
9. Sets

Creating Sets

s = {1, 2, 3}
s = set([1, 2, 2, 3])   # {1, 2, 3} - duplicates removed
s = set()               # empty set (not {}!)
s = set("hello")        # {'h', 'e', 'l', 'o'}

Set Characteristics

  • Unordered - no index access
  • No duplicates
  • Mutable (but elements must be immutable)

Set Methods

s.add(x)        # Add element
s.remove(x)     # Remove (error if not found)
s.discard(x)    # Remove (no error)
s.pop()         # Remove random element
s.clear()       # Remove all

Set Operations

a = {1, 2, 3}
b = {2, 3, 4}

a | b           # Union: {1, 2, 3, 4}
a & b           # Intersection: {2, 3}
a - b           # Difference: {1}
a ^ b           # Symmetric diff: {1, 4}

a.union(b)
a.intersection(b)
a.difference(b)
a.symmetric_difference(b)

Frozenset (Immutable Set)

fs = frozenset([1, 2, 3])
# Cannot add/remove elements
# Can be used as dict key
Key: {} creates empty dict, not set! Use set() for empty set.
