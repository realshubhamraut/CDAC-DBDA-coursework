| test                                                             | real-life example                                                                                                                                                                                                                |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| one-sample z-test                                                | a cereal manufacturer states that each box contains **500 g** of product. an auditor samples 120 boxes (population sd known = 8 g) to test whether the **mean weight actually equals 500 g**.                                    |
| one-sample t-test                                                | a university claims the average **gpa of graduating students** is **3.2**. a professor samples 30 students (population sd unknown) to test if the mean differs from 3.2.                                                         |
| two-sample t-test (independent)                                  | a hospital compares **average blood pressure reduction** between patients using **medication A** vs **medication B**. two independent groups, continuous outcome.                                                                |
| paired t-test                                                    | a company measures **employee productivity** before and after switching to a new software system. the same employees are tested twice → paired differences.                                                                      |
| one-way anova                                                    | a retail chain compares **monthly sales performance** of stores using **three different store layouts** (layout X, Y, Z) to check if mean sales differ across the layouts.                                                       |
| two-way anova                                                    | a school analyses **student test scores** based on two factors: **teaching method (digital/traditional)** and **grade level (8th/9th)** to evaluate main effects + interaction.                                                  |
| one-sample variance test                                         | a manufacturing company requires the **diameter variance of machine-produced bolts** to be **≤ 0.04 cm²**. a sample of bolts is used to test whether the variance exceeds this tolerance.                                        |
| two-sample variance test                                         | a bank checks whether the **variance in monthly expenses** differs between **credit card users** and **debit card users**, to understand financial stability differences.                                                        |
| one-sample proportion test                                       | a logistics company claims **95%** of parcels are delivered on time. out of 400 sampled deliveries, 365 were on time. test if the on-time proportion is really 0.95.                                                             |
| two-sample proportion test                                       | a political campaign tests if the **approval rate** for a candidate differs between **urban voters** and **rural voters**. compares two independent proportions.                                                                 |
| chi-square goodness-of-fit                                       | a zoo expects visitor choices of attractions to follow 50% mammals, 30% birds, 20% reptiles. observed visitor counts differ, so they test whether the distribution fits the expected proportions.                                |
| chi-square test of association                                   | a public health study tests whether **smoking (yes/no)** is associated with **lung disease (yes/no)** using a 2×2 contingency table.                                                                                             |
| one-sample poisson test                                          | a city historically receives **15 emergency calls per hour**. last week, the call center observed 22 calls in an hour. test if the call rate has increased.                                                                      |
| two-sample poisson test                                          | two factories are compared on **accident occurrence rate**: factory A had 18 accidents in 90 days; factory B had 25 accidents in 90 days. test if their rates differ.                                                            |
| pearson correlation (point-biserial when one variable is binary) | a finance company tests whether **income level** is negatively correlated with the probability of **loan default**. income is continuous; default is binary (0/1). tests if higher income is associated with lower default risk. |
